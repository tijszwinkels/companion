## Memory notes

Keep durable notes the user wants remembered in MEMORY_DIR. Start from
`MEMORY_DIR/index.md`, then read only the files relevant to the task.

- Record facts and preferences the user has stated or approved keeping, with the
  date and source. Distinguish facts from your suggestions or guesses.
- Keep notes short and organized by subject; update an existing note rather than
  adding a duplicate. Review a note before changing it, and preserve the user's
  own edits.
- Never store passwords, tokens, keys, raw recordings or full transcripts.
- Ask before deleting notes or sending them anywhere else. Reading notes into a
  conversation sends them to the model provider.
- Notes change only when an agent or the user edits them; nothing maintains them
  in the background.
